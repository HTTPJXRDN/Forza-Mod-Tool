Garage Viewer

Close the game and back up the whole save folder. Work on a copy.

FH6
Save location:
C:\XboxGames\GameSave\pgs\u_<account>_<suffix>\current\ContainersRoot\User_<account>\C_ProfileData

1. Load C_ProfileData. The built-in stock-car list loads automatically.
2. Select owned cars or cars to add. Ctrl/Shift-click selects several.
3. Click Apply car fields to keep field edits in the working copy. For a batch, check only the fields you want changed.
4. Add, Remove, Duplicate and Set as current car have their own buttons.
5. Export save writes C_ProfileData.garage-edited. Install an encrypted copy as C_ProfileData.

- Missing cars only hides models you already own. Traffic cars have a separate experimental list.
- Adding supported non-DLC cars also updates their Collection Journal entries. DLC ownership is still required.
- If an action is disabled, check the status message.
- Revert all edits discards this tab's changes.

FH2/Azimuth
- FH2 save opens a revision or revisions folder.
- Add, duplicate or remove cars, and edit owner, distance or top speed.
- For batch owner edits, select cars, enter the label and Apply Original Owner. Empty text clears it. This does not change your account.
- Distance and top speed are single-car edits. Cars in use and barn-find cars are protected.
- Close FH2 and Azimuth and back up your User save folder before installing.
- Copy the exported commit and whole data folder into BOTH folders inside revisions. Replacing only one can stop the edited save loading.
- Keep both folder names; their revision numbers change.

Use Auto-find or choose a thumbnail folder for previews. FH2 shows stock previews. Export and reload to move edits between tabs.
