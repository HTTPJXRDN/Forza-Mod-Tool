# Forza Mod Tool 1.2.6.2

Changes from 1.2.6.1:

- Discover all roads and unlock save-managed clothes/horns in Profile Editor.
- Complete Collection Journal challenges with automatic points, bonuses and Festival wristbands. Ctrl+A selects all listed challenges; clear filters first for the full journal.
- Dark/pink confirmations, shorter journal instructions and matching tickboxes/scrollbars. Snapshot export, decal unlock and manual wristband controls are removed.
- Export several cars into one donor DB, and optionally Drop & rebuild those cars when importing.
- Normal merges/imports preserve the receiving GameDB's VersionInfo; only Merge updated DB advances it.

The project owner has confirmed the new profile features working in-game. Keep a full save backup and close the game before installing an edited export. The tool changes private working copies only; Save edited/Export creates a separate file. VIP/DLC ownership and online records are not granted or changed.

Extract the whole ZIP and run FH6ModStudio.exe. Keep the ACL helpers and licenses folder beside it. The protected Windows x64 EXE is self-contained. A separate clean source ZIP includes the unchanged protected crypto runtime, not raw keys/private crypto source. FM LZX rebuilding still requires your legally obtained x64 xcompress64.dll; it is not included.

See README.md and CHANGELOG.md in the repository for full instructions/history.
